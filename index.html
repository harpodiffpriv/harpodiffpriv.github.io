SoK: A Practical Black-Box Framework for Evaluating Differential Privacy in Cyber-Physical Systems

We present a systematization of knowledge (SoK) and a "black-box" scoring framework, Harpo, that quantitatively evaluates papers in this domain along three dimensions: privacy, utility, and safety. Our findings reveal clear patterns, highlighting the need for a cross-dimensional approach in future CPS design.

View Artifacts on GitHub

Introduction

Privacy has become increasingly important due to the rapid development of autonomous systems (AS) and cyber-physical systems (CPS). These systems are used in critical applications such as industrial control and healthcare, raising concerns about the privacy of sensitive data like task execution times and sensor readings. Differential Privacy (DP) techniques have become contenders to improve both the privacy and security of such systems, yet a comprehensive framework for evaluation is still lacking.

The "Harpo" Black Box Framework

We propose a framework, Harpo, that functions as a black box. It accepts a research paper (represented as a JSON configuration) as input and produces normalized scores for three key metrics.
